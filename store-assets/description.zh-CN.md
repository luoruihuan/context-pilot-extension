# Context Pilot

在 Chrome 侧边栏中使用你自己的 AI 服务，理解、总结和比较你主动选择的网页。

Context Pilot 支持 OpenAI Chat Completions 兼容接口与 Anthropic Messages 接口。你可以询问当前页面，也可以输入 `@` 选择最多 10 个已打开页签，获得带来源编号的联合分析。每次发送前都会重新读取页面，因此可获取 SPA 路由和动态内容的最新状态；单个页面读取失败时，其余页面仍可继续分析。

主要功能：

- 当前页总结、要点提取、信息查找与表格分析
- `@` 多页签选择、跨页面比较和可回溯来源
- 流式回答、停止生成、用量显示与本地历史恢复
- 创建、测试、编辑和删除 OpenAI-compatible / Anthropic 模型配置
- API Key 由用户自备并仅保存在浏览器本地

隐私说明：网页内容和问题从浏览器直接发送到用户配置的模型服务地址。开发者不运营中转服务器，不接收 API Key、网页正文或对话内容。扩展只在用户发起提问并选择页面时读取内容。
