# Context Pilot 隐私政策

生效日期：2026-09-01

Context Pilot 是一款 Bring Your Own Key（BYOK）浏览器扩展。本文说明扩展在本地如何处理数据。本文件必须在上架前发布到稳定、公开的 HTTPS 地址；仓库中的文件不是已上线隐私政策 URL。

## 处理的数据

- 身份验证信息：用户输入的模型 API Key、模型地址和模型名称。配置保存在 `chrome.storage.local`，仅扩展受信任上下文可读取。
- 网站内容：用户主动选择页面的标题、URL、可见正文、标题层级、列表和表格；只在用户发送问题时临时提取。
- 用户内容：问题、模型回答、来源标题/URL和时间信息。对话历史保存在浏览器本地 IndexedDB。
- 技术用量：模型服务返回的输入/输出 token 数，仅在当前界面展示。

## 使用、共享与保留

网站内容、问题和必要的对话上下文从浏览器直接发送到用户配置并授权的 OpenAI-compatible 或 Anthropic 服务。开发者不运营中转服务器，不接收或出售这些数据，也不将其用于广告、信用、画像或与扩展核心功能无关的用途。

API Key、网页正文和模型响应不会发送给开发者。网页正文不会持久化；模型配置和会话历史保留在用户本地，直到用户在扩展中删除配置/会话、清除扩展数据或卸载扩展。

上述数据使用仅限于提供和改进用户明确请求的单一用途，遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）。

## 用户控制与删除

用户可在“模型设置”删除单个配置，在“对话历史”删除单个会话，或通过 Chrome 的扩展数据清理/卸载功能删除全部本地数据。网页正文无需单独删除，因为扩展不持久化正文。

如需支持或数据删除协助，请使用 Chrome Web Store 商品详情页中上架前配置的真实支持邮箱或支持页面。当前仓库未提供也未虚构可联系地址。

## 安全与变更

扩展不加载远程代码，不在 URL 或日志中放置 API Key，并将模型请求限制到用户保存且授权的 origin。政策更新会随扩展版本发布；若处理目的发生实质变化，将在生效前更新公开政策。
